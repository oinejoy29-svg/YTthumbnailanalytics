プライバシーポリシー

本サイトは、YouTube API Servicesを利用して、 サイト運営者自身が管理するYouTubeチャンネルの 動画およびチャンネルに関するデータを取得・表示しています。

取得する情報

YouTube API Servicesを通じて、 サイト運営者自身が管理するYouTubeチャンネルの 動画情報、再生状況、チャンネル分析情報等を取得する場合があります。

情報の利用目的

取得した情報は、サイト運営者自身による YouTubeチャンネルの分析および表示のために利用します。

第三者への提供

取得したGoogleユーザーデータを、 本サイトの分析機能に必要な場合を除き、 第三者へ販売または提供することはありません。

データの保存

取得したデータの一部は、 チャンネルの分析および過去データとの比較のために保存される場合があります。

Google API Services

本サイトによるGoogle APIから取得した情報の利用には、 Google API Services User Data Policyが適用されます。

お問い合わせ

本サイトに関するお問い合わせは、 サイト運営者までご連絡ください。
